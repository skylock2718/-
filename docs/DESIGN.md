# 命骰远征 · DICEBOUND — 设计文档

> 跑团式卡牌战棋 · Roguelite Dice-Tactics Card Battler
>
> 一句话：**在一张有高低差的立体沙盘上，用 20 张牌召唤英雄小队，每一次攻击、豁免、检定都由骰子决定；走过一条条岔路，拿遗物、学专长，直到推翻操纵命运的「骰主」。**

---

## 0. 设计支柱

| 支柱 | 含义 | 落地方式 |
| --- | --- | --- |
| **骰子即命运** | 每次出手都要掷骰，结果透明、可预估、可干预 | d20 攻击检定 vs AC、豁免 vs DC、优势/劣势、大成功/大失败、命运点重掷、业力骰 |
| **地形即战术** | 高度、视线、地表元素、资源点让站位比数值更重要 | 高低差（±2 命中 / 射程 +1 / 坠落伤害）、悬崖遮挡视线、森林掩体、法力泉/命运神龛/召唤法阵 |
| **牌组即流派** | 20 张牌的上限迫使取舍，构筑出不同流派 | 5 名英雄 × 2 条以上流派 + 中立牌、装备牌、地形牌 |
| **每局都不同** | 地图、事件、遗物、专长组合每次都不一样 | 杀戮尖塔式分支地图 + 程序生成战场 + 遗物/专长/药水 |
| **桌游的手感** | 像在桌上推着纸板立牌跑团 | 3D 微缩沙盘、纸板立牌单位、真·3D 多面骰、DM 叙事事件 |

## 2. 核心循环

```
选择英雄 ─▶ 远征地图（分支路线） ─▶ 节点
                                    ├─ ⚔ 战斗 / ☠ 精英 / ♛ 首领 ─▶ 战棋对局 ─▶ 奖励（金币/卡牌三选一/药水/遗物/经验）
                                    ├─ ? 事件 ─▶ DM 叙事 + d20 技能检定
                                    ├─ ⚖ 商店 ─▶ 买卡/遗物/药水、移除卡牌
                                    ├─ ✦ 篝火 ─▶ 长休回血 / 磨砺升级卡牌 / 冥想
                                    └─ ✧ 宝藏 ─▶ 遗物
升级 ─▶ 三选一专长（Feat） ……  击败三章首领 ─▶ 夺回「天命之骰」
```

- **完整远征**：3 章（翡翠林地 → 灰烬荒原 → 星穹尖塔），每章约 9 层。
- **短篇远征**：只打第一章，适合 30 分钟体验。
- **自由对战**：任选英雄 + 自组 20 张牌，1v1 或 3~4 人混战（FFA），用于验证多人混战架构。

## 3. 战斗规则

### 3.1 棋盘
- 方格棋盘（1v1 默认 9×9，精英/首领 10×10，混战 11×11），四向移动。
- 每格有：**高度**（0~4）、**地形**、**地表**（动态元素）、**节点**。

| 地形 | 移动 | 说明 |
| --- | --- | --- |
| 平地（草/土/沙/雪/石） | 1 | — |
| 森林 | 1 | 站在其中对远程攻击 **+2 AC（掩体）** |
| 浅水 | 2 | 受到闪电伤害时，相连水域内所有单位一起感电 |
| 深水 / 岩柱 / 废墟 | 不可通行 | 飞行可越过深水；岩柱与废墟会遮挡视线 |
| 熔岩 | 1 | 进入或回合开始时受到 2d6 火焰伤害 |

### 3.2 高低差（纵深策略）
- **攀爬**：每升高 1 层多消耗 1 点移动；单位的 Jump 值决定一步最多能爬几层（默认 1），下跳可比 Jump 多 1 层。飞行无视高度。
- **高地优势**（参考 BG3）：攻击者比目标高 ≥1 层 → **命中 +2**；低 ≥1 层 → **命中 −2**。
- **居高临下**：远程单位比目标高 ≥2 层 → **射程 +1**。
- **视线**：远程攻击和指向性法术要求视线；从攻击者「眼高」到目标的连线若被更高的悬崖、岩柱遮挡则无法选取。
- **坠落**：被击退下落 ≥2 层时，每超过 1 层受到 1d6 伤害；撞上障碍或单位双方各受 1d4。

### 3.3 掷骰
- **攻击检定**：d20 + 命中加值 + 修正 ≥ 目标 AC → 命中。
  - 天然 20：必中且 **暴击**（伤害骰数量翻倍）；天然 1：必失。
  - **优势**：掷两次取高；**劣势**：取低；二者抵消。
  - 优势来源：夹击（目标另一侧有友军）、目标眩晕/冻结/定身/倒地、潜行偷袭、群狼战术……
  - 劣势来源：中毒、恐惧、远程攻击时身边贴着敌人、攻击倒地目标的远程……
- **豁免**：目标掷 d20 + 豁免加值（强韧 / 反射 / 意志）≥ 法术 DC → 成功（常见为伤害减半）。
- **技能检定**：事件与战场宝箱使用英雄六维（力/敏/体/智/感/魅）调整值 + 熟练加值 vs DC。
- **命运点**（灵感）：上限 3。掷出天然 20、控制命运神龛可获得；花 1 点可 **重掷自己刚刚失败的 d20**。
- **业力骰**（可在设置中关闭）：连续失败后，下一次失败的检定会被悄悄重掷一次，防止连败——只对玩家生效。
- 战前预览：悬停目标即显示 **命中率、暴击率、伤害区间与所有修正来源**。

### 3.4 回合与资源
- 先手 2 点法力上限，后手 3 点；每回合上限 +1，最高 9；回合开始补满。
- 每回合抽 2 张，手牌上限 7；每回合可 **换牌 1 次**（Duelyst）；每名玩家场上最多 7 个非英雄单位。
- 第 15 轮起「命运之潮」：每回合开始时英雄受到逐轮递增的伤害，避免僵局。
- 每个单位每回合：**移动力** + **1 次行动**（攻击/技能），可以先打后走（BG3 式拆分移动）。
- 召唤：在 **英雄周围 8 格** 或 **己方控制的召唤法阵周围** 的空地召唤；新召唤的单位本回合不能行动（「疾驰」除外）。
- 胜利条件：击杀敌方英雄（混战中最后存活者获胜）。

### 3.5 战场节点
| 节点 | 效果 |
| --- | --- |
| 💧 法力泉 | 控制方回合开始 +1 法力 |
| 🎲 命运神龛 | 控制方回合开始 +1 命运点 |
| 🌀 召唤法阵 | 控制方可在其周围召唤 |
| 🌿 治愈泉 | 回合开始站在上面的单位回复 3 生命 |
| 🧰 宝箱（事件） | 首个踏上的单位触发 **敏捷 DC 12** 检定：成功抽 2 张，失败中陷阱再抽 1 张 |
| 🗿 祭坛（事件） | **感知 DC 13**：成功获得祝福并回复，失败受到灾祸 |
| 🔮 符文石（事件） | **智力 DC 14**：成功 +1 命运点 +1 法力 |
| 💰 金币堆（事件） | 玩家拿到获得远征金币 |

单位结束移动停在资源节点上即占领，直到被敌人踩上为止。

### 3.6 地表元素（神界原罪 2 式联动）
| 地表 | 效果 | 联动 |
| --- | --- | --- |
| 火焰 | 回合开始 1d4 火焰伤害并「燃烧」 | 引燃油脂（爆燃 2d6）；融化冰面 |
| 油脂 | 移动 +1 | 遇火爆燃 |
| 冰面 | 踏上需反射 DC 10，失败倒地 | 冰系法术可把浅水冻成冰面 |
| 毒雾 | 回合开始 1d4 毒素并「中毒」 | — |
| 圣光 | 施放者友军回合开始回复 2；亡灵受伤 | — |

## 4. 卡牌

- **人物牌**：召唤单位上场（HP、AC、命中、伤害骰、移动、射程、关键词、技能）。
- **法术牌**：以英雄为施法原点，射程从英雄所在格计算。
- **装备牌**：挂到友方单位身上，直到该单位阵亡。
- **地形牌**：抬升 / 下沉地块、制造森林、油脂、冰面、圣光地面……直接改写高低差。
- 稀有度：普通 / 稀有 / 史诗 / 传说；每张牌可升级一次（+）。
- **牌组上限 20 张**：远征中满 20 张后获得新牌必须替换一张——每一张都是取舍。

### 4.1 英雄与流派

| 英雄 | 定位 | 英雄技能 | 流派 A | 流派 B |
| --- | --- | --- | --- | --- |
| 奥德里克 · 圣骑士 | 前排指挥 | 圣疗：治疗贴身友军 | **盾墙**：嘲讽、坚守、反击、光环 | **圣光审判**：惩击、祝福、圣光地面、护盾 |
| 希尔瓦 · 游侠 | 高地射手 | 猎人印记：额外 1d6 | **高地狙击**：抬升地形、远程、居高临下、暴击 | **兽群**：狼、熊、鹰，群狼战术 |
| 莫温 · 元素法师 | 后排法核 | 火焰箭 | **焚烬**：火球、油脂、燃烧连锁 | **风暴寒霜**：闪电连锁、冻结水面、控制 |
| 洛克 · 命运赌徒 | 骰子操纵 | 灌铅骰：下一次 d20 获得优势 | **赌命**：命运点、孤注一掷、扩大暴击范围 | **暗影**：潜行、偷袭、毒刃 |
| 莫尔萨 · 死灵术士 | 召唤海 | 亡者复苏：在尸体处召唤骷髅 | **亡灵大军**：廉价骷髅、遗言 | **献祭**：牺牲友军换取爆发 |

## 5. 远征（Roguelite）

- **地图**：7 列 × N 层，6 条路径自下而上生成、互不交叉；首层必为战斗，首领前必为篝火，中段保证宝藏。
- **英雄生命跨战斗保留**；召唤的单位每场战斗重新从牌组召唤。
- **奖励**：普通战斗金币 + 卡牌三选一 + 药水概率；精英额外遗物；首领给首领遗物 + 升级。
- **升级与专长**：战斗获得经验，升级时 +最大生命并在三个 **专长**（幸运儿、神射手、巨武器大师、坚韧、警觉、战争施法者……）中选择一个。
- **商店**：卡牌、遗物、药水、移除卡牌（价格递增）。
- **篝火**（四选一）：休息（回复 30% 生命）/ 锻造（升级一张牌）/ 训练（+2 经验）/ 净化（牌组里有诅咒时，烧掉一张诅咒）。
- **牌组上限 20 张**：获得新牌时若已满，必须选择一张旧牌替换，或者放弃新牌。
- **事件**：DM 叙事 + 多选项，选项标注所需检定与成功率，掷骰界面完全仿照 BG3。
- **诅咒牌**：部分事件会塞入无法打出的诅咒牌，污染牌组。
- **药水**：3 个栏位，战斗中免费使用。
- **难度（天命等级 0~5）**：用某位英雄通关后解锁该英雄的下一级；敌人生命/命中/法力逐级提高，金币与篝火回复逐级减少。
- **存档**：远征每一步自动保存到浏览器本地；战斗中退出后，继续时从该场战斗重新开始。

### 5.1 自由对战与牌组构筑

- 模式：1v1、三人混战、四人混战、2v2（相邻出生点为队友）；每个席位可选玩家或三档 AI，多名玩家时为同屏热座，全部 AI 时为观战。
- 战场：三种生物群系 × 9/11/13 格地图。
- 牌组构筑：20 张、同名最多 2 张（传说 1 张），可用职业牌 + 中立牌；每位英雄自带两套预组（对应两条流派），自建牌组保存在本地。

### 5.2 新手引导

- 首场战斗按局面依次弹出提示（移动、召唤、命中率、资源点、命运点、结束回合、镜头），每条只出现一次，可在设置中关闭或重置。

## 6. 美术与表现

- **风格**：「烛光下的桌面沙盘」——低多边形 3D 微缩地形、暖色烛光与冷色魔法辉光、柔和阴影与泛光（Bloom）。
- **单位**：纸板立牌（Standee）+ 阵营色底座，移动时一格一格「跳」，阵亡时向后倒下并化作粒子——就像真的在桌上推棋子。
- **卡面**：程序化绘制的背景（渐变 + 噪点 + 光束）+ game-icons.net 剪影插画，按稀有度不同边框；史诗/传说带镭射光泽；悬停时 3D 倾斜并跟随鼠标反光。
- **骰子**：真 3D 多面骰（d4/d6/d8/d10/d12/d20），数字贴图逐面生成；先由随机数决定结果，再让骰子翻滚并精确停在该面。
- **特效**：粒子系统（火花、烟、余烬、治疗光点）、投射物拖尾、闪电折线、冲击波、法阵、镜头震动（按伤害分级）、浮动伤害数字（暴击放大 + 抖动）。
- **音频**：WebAudio 实时合成音效（骰子碰撞、刀剑、法术、爆炸）与生成式环境音乐，无需任何音频素材。

## 7. 技术架构

```
src/
  core/    纯逻辑：随机数、骰子、棋盘与寻路、视线、战斗状态机、效果解释器、AI、地图生成（可在 Node 中无头运行）
  data/    数据驱动的内容：卡牌、英雄、遗物、药水、专长、事件、遭遇、生物群系
  run/     远征：分支地图、奖励、商店、存档与解锁
  render/  Three.js：沙盘、立牌、粒子特效、3D 骰子、表现层（把战斗事件翻译成动画）
  ui/      Preact：所有界面与战斗 HUD
  audio/   WebAudio 合成音效与音乐
```

- 战斗引擎是 **异步事件流**：引擎每结算一步就 `await io.emit(event)`，表现层播放对应动画后再继续，保证「先看到骰子、再看到刀砍下去、最后血条变化」的节奏；无头模式下 `emit` 立即返回，用于 AI 对战模拟与平衡测试。
- 引擎内置 N 名玩家与队伍概念，1v1 与多人混战共用同一套规则。
- 全部随机性来自可序列化的种子随机数，存档可复现。
